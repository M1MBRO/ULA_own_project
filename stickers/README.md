# Стікер-пак (die-cut) — генератор наліпок з білою обводкою

Автоматично робить із зображень готові до друку наліпки: прибирає фон,
додає білу обводку по контуру (як на «BE A DONOR / BE A HERO»), вирівнює
розмір під друк і генерує лінію різу (die-line) для друкарні.

## Як користуватися

1. Поклади зображення у `input/` (jpeg / png / webp).
2. Запусти:
   ```bash
   pip install -r requirements.txt   # один раз
   python make_stickers.py
   ```
3. Забери результат:
   - `output/png/`      — готові наліпки (RGBA PNG, 300 DPI)
   - `output/dieline/`  — лінія різу для друкарні (PNG + SVG)
   - `output/preview/contact_sheet.png` — аркуш для перегляду всіх наліпок

Щоб додати нові наліпки — просто докинь файли в `input/` і запусти знову.

## Налаштування (у блоці CONFIG в `make_stickers.py`)

| Параметр         | Що робить                                   | Замовч. |
|------------------|---------------------------------------------|---------|
| `TARGET_CM`      | довша сторона наліпки, см                    | 5.0     |
| `DPI`            | роздільність для друку                       | 300     |
| `BORDER_RATIO`   | товщина білої обводки (частка від фігури)    | 0.045   |
| `BORDER_PX`      | жорстко задати товщину обводки в px          | None    |
| `SMOOTH_RATIO`   | округлення кутів обводки                     | 0.6     |
| `BLEED_MM`       | прозорий припуск навколо для друку, мм       | 3.0     |
| `MIN_COMP_RATIO` | поріг прибирання дрібних уламків             | 0.005   |
| `ADD_KEYLINE`    | тонка сіра лінія зовні білого               | False   |

## Поради щодо вихідних зображень

Найкраще працює з чистою векторною/кліп-арт-графікою на однотонному фоні.
Фото надрукованих об'єктів (напр. малюнок на футболці) дають гірший результат —
для них краще знайти оригінальну графіку без фону.

## Друк

Більшість друкарень приймають RGB PNG @300DPI. Якщо вимагають CMYK —
повідом, додамо конвертацію з ICC-профілем. Для die-cut друку передавай
у друкарню і PNG, і відповідний файл із `output/dieline/` (контур різу).
